# FindIt 🧭
### Smart Lost & Found Management System

---

## 📌 Overview
FindIt is a Spring Boot REST API designed to help users report, track, and recover lost items efficiently.
The system connects people who have lost items with those who have found them through an intelligent matching mechanism.

---

## 🎯 Problem Statement
Losing personal belongings in public places often leads to frustration due to the lack of a centralized and reliable system for reporting and tracking lost items.

---

## 💡 Solution
FindIt provides a centralized platform where users can:
- Report lost items
- Report found items
- Automatically match lost and found reports
- Submit claims to recover items
- Track the status of their reports

---

## ⚙️ Tech Stack
- Java 17+
- Spring Boot
- Spring Data JPA
- Spring Security (JWT) 
- PostgreSQL
- Maven

---

## 🧩 Core Features
- 📄 Create and manage lost/found item reports
- 🔍 Matching system between lost and found items
- 📨 Claim submission and verification
- 🔔 Notification system (planned)
- 🔐 Authentication & authorization (planned)
